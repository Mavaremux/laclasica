# Pizzería La Clásica

Sitio web estático listo para alojar en GitHub Pages, Netlify o un servidor HTTP estático.

## Archivos principales
- `index.html`: página principal y base de datos de menús integrada en JavaScript.
- `styles.css` y `script.js`: interfaz y comportamiento.
- `config.js`: teléfono de WhatsApp existente. Verificar con el cliente antes de publicar.
- `CAMBIOS_MENU_2026.md`: cambios hechos a partir de los menús proporcionados.
- `AUDITORIA_PRECIOS_NAPOLETANA.md`: lista de las 14 pizzas napolitanas con los precios de la fotografía.

## Publicación
Subir el contenido completo de esta carpeta a la raíz del repositorio o carpeta de publicación. No necesita npm ni compilación.

**Nota:** los archivos OGG de WhatsApp fueron accesibles para reproducción, pero no hubo una transcripción verificada de sus instrucciones. Solicitar el texto de los audios para cerrar cualquier ajuste adicional pendiente.
