# Pizzería La Clásica — sitio editorial

Proyecto estático, responsive y sin dependencias: abre `index.html` en un navegador o publícalo en cualquier hosting estático.

## Antes de publicar

1. En `config.js`, agrega el número real en formato internacional a `WHATSAPP_NUMBER`.
2. Reemplaza todas las imágenes que llevan la etiqueta `IMAGEN DE REEMPLAZO` por los assets oficiales. Las URLs están centralizadas de forma visible en `index.html`.
3. Confirma precios, horarios, teléfonos, direcciones, menús y el uso autorizado de los reconocimientos.

Los botones de cada producto generan un mensaje de WhatsApp con el nombre de la pizza. No existe carrito, checkout ni pagos.
